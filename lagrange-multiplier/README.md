# 為什麼需要 Lagrange Multipliers？

互動式教學網頁，說明受約束極值問題中，Lagrange multiplier 法比消去變數更自然的幾何原因。

## 教學目標

1. 消去變數 ≡ 在局部把約束曲線表示成 y=y(x) 或 x=x(y)
2. 哪種表示方式方便，取決於曲線的局部切線方向
3. 求出極值點之前，通常不知道哪種表示法合適
4. Lagrange multiplier 直接利用梯度平行的幾何條件，不必預先選定獨立變數

## 數學模型

- **約束曲線**：旋轉橢圓 g(x,y) = u²/a² + v²/b² − 1 = 0
- **目標函數**：旋轉雙曲線族 F(x,y) = p² − q²

## 互動功能

- 滑桿控制橢圓旋轉角 θ（−90° 至 90°）
- 滑桿控制等值線旋轉角 φ（−90° 至 90°）
- 切換獨立變數（x 或 y），顯示局部隱函數表示的有效性
- 核取方塊控制梯度向量、切線、等值線的顯示
- 全部數值由參數計算，非硬編碼
